## הפעלה מקומית

```bash
cd hebrew-quest && python3 -m http.server 8123
```

ואז לפתוח `http://localhost:8123`. **חובה שרת** — פתיחת `index.html` ישירות מהדיסק לא תעבוד (ES modules ו-fetch חסומים ב-`file://`).

## בדיקות

```bash
npm run check
```

מריץ ולידציה מלאה של בנקי התוכן (תבניות כתיב, אינדקסי תשובות, הפניות בין ימים לטקסטים, התאמת מילון לטקסט) ואת בדיקות מנוע החזרה המרווחת.

## פריסה ל-GitHub Pages

```bash
cd hebrew-quest
git init && git add -A && git commit -m "מכרה המילים"
git branch -M main
```

צור ריפו **פרטי או ציבורי** בשם `hebrew-quest` ב-github.com, ואז:

```bash
git remote add origin git@github.com:<המשתמש-שלך>/hebrew-quest.git
git push -u origin main
```

בריפו: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
אחרי כדקה הקישור יהיה `https://<המשתמש-שלך>.github.io/hebrew-quest/`.

> שים לב: GitHub Pages מגיש רק ריפו ציבורי בחשבון חינמי. אין באפליקציה נתונים אישיים — ההתקדמות נשמרת במכשיר בלבד — אבל אם זה מפריע, אפשר להעלות במקום זה ל-Netlify Drop (גרירת התיקייה לדפדפן, בלי חשבון).

**בכל עדכון:** העלה את מספר הגרסה ב-`sw.js` (`const VERSION = 'hq-v3'`) לפני ה-push. אחרת המכשיר עלול להישאר עם מטמון ישן.

## התקנה על האייפון

1. לפתוח את הקישור ב-**Safari** (לא בכרום).
2. כפתור השיתוף → **הוספה למסך הבית**.
3. לפתוח מהאייקון. במסך הפתיחה, הלחיצה על "בוא נתחיל" היא זו שפותחת את הקול — זו דרישה של iOS.

אם לא נשמעת עברית, האפליקציה עוברת אוטומטית ל"מצב הבהוב" (המילה מוצגת לרגע במקום להיקרא) והתרגול נשאר תקף. הקול Carmit מובנה בכל אייפון; אפשר לוודא ב-הגדרות → נגישות → תוכן מדובר → קולות → עברית.

## מסך ההורה

**מקומית (על המכשיר שלו):** לחיצה ארוכה של 2.5 שניות על אייקון המכוש במסך הבית → הגדרת קוד בן 4 ספרות.

**מרחוק (מהטלפון שלך):** דורש חיבור Supabase חינמי:

1. פתח פרויקט ב-[supabase.com](https://supabase.com).
2. SQL Editor → הדבק והרץ את `tools/supabase.sql`.
3. Settings → API → העתק את ה-Project URL ואת מפתח ה-**anon** לתוך `js/config.js`.
4. push מחדש. מתוך האפליקציה, במסך ההורה, יופיע קישור אישי — שמור אותו.

הדשבורד מציג: ימים שהושלמו ורצף · דיוק לפי ארבעת התחומים · טבלת מיומנויות מהחלשה לחזקה · המילים והכללים שחוזרים כטעות · מילים שהילד סימן כלא-מוכרות בטקסטים · לוח 28 הימים · מה שהוא כתב בתחנות הכתיבה · המלצה אוטומטית · ייצוא CSV.

**מה שנשלח לענן:** אחוזי הצלחה, מילים שגויות, ותשובות הכתיבה. **מה שלא:** שם מלא, מייל, הקלטות, או כל מזהה אחר.
מפתח ה-anon גלוי בקוד (זה התקן של Supabase), ולכן הגישה עוברת דרך שתי פונקציות RPC שמחייבות את מפתח הילד — בלי המפתח אי אפשר לדלות רשימת ילדים. הקישור לדשבורד הוא עצמו הסוד.

## עריכת תוכן

כל התוכן ב-`data/`, בלי קוד:

- **`spelling.json`** — כל פריט הוא `["תבנית", "הקראה מנוקדת", "הסבר"]`. התבנית מסמנת את הפער: `{נכון|שגוי}`. אפשרות ריקה = אין שם אות: `מ{|י}שפחה` (הנכון: משפחה), `ע{י|}ר` (הנכון: עיר). ההקראה היא כתיב **חסר מנוקד** — כך הקול לא טועה בהגייה.
- **`vocab.json`** — מילה, הגדרה, 3 מסיחים, משפט השלמה עם `___`, ואופציונלית נרדף/ניגוד ומשפטי שימוש נכון/שגוי.
- **`grammar.json`** — חמישה סוגי פריטים: `sort` (מיון לקטגוריות), `choose` (בחירת צורה), `inflect` (הטיה בהקלדה), `sentence` (סידור מילים), `root` (איתור המתחזה במשפחה).
- **`texts.json`** — טקסט כמערך משפטים (מאפשר הקראה משפט-משפט וסימון בתוך הטקסט) + שאלות מסוג `mc` / `find` / `order` / `factop` / `short`.
- **`curriculum.json`** — שיבוץ 28 הימים לתחנות.

אחרי כל שינוי הרץ `npm run check`.

## ארכיטקטורה

HTML + CSS + Vanilla JS (ES modules), **בלי build step**. כל תחנה היא מודול ב-`js/games/` שמממש `render(item, api)` בלבד; התור, הלבבות, המשוב והניקוד מטופלים ב-`games/common.js`. ה-SRS (`js/srs.js`) מקבל אירועים אחידים ולכן חזרות חוצות תחומים — מילת אוצר מילים תחזור בתוך תרגיל כתיב.

האפליקציה **local-first**: היא עובדת מלאה בלי רשת ובלי Supabase; הסנכרון הוא best-effort בלבד. ה-service worker הוא network-first עם נפילה למטמון — טריות חשובה כאן יותר מחיסכון, כי תוכן מתעדכן.

## מה זה לא

אין כאן פרסומות, אין analytics, ואין נכסים או שמות של משחקים מסחריים — עולם הקוביות מקורי לגמרי.
